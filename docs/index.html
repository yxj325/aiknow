快速开始

# 1. 克隆仓库
git clone https://github.com/yxj325/aiknow.git
cd aiknow

# 2. 安装依赖
pip install -r aiknow/requirements.txt

# 3. 初始化 & 启动
python aiknow/scripts/init.py
python aiknow/run.py

# 4. 打开浏览器访问
# Web: http://localhost:8000/ui
# API: http://localhost:8000/docs
